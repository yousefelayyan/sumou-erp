# السمو ERP

نظام محاسبي متكامل متعدد الشركات (ويب + تطبيق PWA)، مبني على Supabase.

- `sql/` ملفات قاعدة البيانات، بالترتيب (01، 02، ...)، تُشغّل من Supabase ← SQL Editor.
- `app/` واجهة النظام (HTML/CSS/JS بدون أدوات بناء).

المفتاح الموجود في `app/config.js` هو المفتاح العام (publishable)، وآمن للنشر. الحماية من سياسات RLS بقاعدة البيانات.

## المراحل
1. ✅ الأساس: الدخول، المستخدمين والصلاحيات، الشركات، السنوات المالية، سجل النشاط
2. المالية: دليل الحسابات، الأرصدة الافتتاحية، السندات، الترحيل
3. التقارير المالية
4. الزبائن والموردين
5. المبيعات والمشتريات
6. الضرائب والفوترة الإلكترونية
7. الأوراق التجارية
8. المخزون
9. متابعة إقرارات العملاء
10. إغلاق السنة
