# السمو ERP

نظام محاسبي متكامل متعدد الشركات (ويب + تطبيق PWA)، مبني على Supabase.

- `sql/` ملفات قاعدة البيانات، بالترتيب (01، 02، ...)، تُشغّل من Supabase ← SQL Editor.
- `docs/` واجهة النظام (HTML/CSS/JS بدون أدوات بناء).

المفتاح الموجود في `docs/config.js` هو المفتاح العام (publishable)، وآمن للنشر. الحماية من سياسات RLS بقاعدة البيانات.

## المراحل
1. ✅ الأساس: الدخول، المستخدمين والصلاحيات، الشركات، السنوات المالية، سجل النشاط
2. ✅ المالية: دليل الحسابات، الأرصدة الافتتاحية، سندات القيد والقبض والصرف، الترحيل والقيد العكسي
3. ✅ التقارير المالية: كشف حساب، اليومية العامة، ميزان المراجعة، قائمة الدخل، الميزانية العمومية
4. ✅ الزبائن والموردين: البطاقات، كشف حساب الطرف، أعمار الذمم
5. ✅ المبيعات والمشتريات: الأصناف، الفواتير والمرتجعات، القيد التلقائي، حسابات الربط
6. ✅ ضريبة المبيعات: كشف الإقرار (والفوترة الإلكترونية جوفوترة لاحقاً)
7. محفظة الشيكات
8. المخزون والجرد
9. ✅ متابعة إقرارات العملاء ومواعيدها
10. إغلاق السنة وتدوير الأرصدة

## تشغيل قاعدة البيانات
الأسهل: `sql/ALL_IN_ONE.sql` (فيه كل المراحل، آمن للتشغيل أكثر من مرة).
